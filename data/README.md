# Data

`raw/DEXMXUS.csv` — Mexican pesos to one U.S. dollar, daily noon buying rates in
New York, from the Board of Governors of the Federal Reserve System (H.10
release), distributed by FRED, Federal Reserve Bank of St. Louis:
<https://fred.stlouisfed.org/series/DEXMXUS>.

| Item | Value |
|---|---|
| Downloaded | 24 October 2026 (FRED CSV export, unmodified) |
| Coverage | 8 November 1993 – 16 October 2026 |
| Rows | 8,595 (337 empty values on U.S. holidays) |
| SHA-256 | `60c8c775e7308e070bad43c65386f7b3855d65410101ba496f15c5df85187738` |

The file is used exactly as downloaded. The code verifies the checksum before
every run and stops if the file differs. FRED may revise or extend the series;
to reproduce the article, use this snapshot rather than a fresh download.

Terms of use: FRED states that data from the Board of Governors are in the
public domain, but check <https://fred.stlouisfed.org/legal/> before
redistributing, and cite the series as above.
